# Préférences durables du chef de projet

Une ligne par préférence, datée. Exemples hérités du démonstrateur, à confirmer avec le chef de projet :
- Pas de tiret long dans les textes.
- Un seul fichier par document : pas de versions multiples.
- Écrire « chiffrage à confirmer » plutôt qu'engager un tiers au futur.
